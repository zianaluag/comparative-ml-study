## About

We predict whether a DPWH infrastructure project will be delayed, using information known when the contract is awarded.

## Dataset

- [DPWH Infrastructure Projects Data](https://data.bettergov.ph/datasets/19/resources/406) (BetterGov Open Data Portal)
- Planned end dates and bidding details from the [DPWH Transparency Portal](https://transparency.dpwh.gov.ph/)

## Methods

1. Spline logistic regression
2. XGBoost-style gradient boosted trees
3. k-Nearest Neighbors
